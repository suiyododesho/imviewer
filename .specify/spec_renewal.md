# メンテナンス速度アップ対応後の仕様差分

本ドキュメントは、ベース仕様である(spec.md)[spec.md]から、(M06)[M06/tasks.md]のメンテナンス速度アップ対応後に変更される仕様の差分を記録するものです。

## 仕様差分の管理方法

- 仕様差分は、M06の実装完了後に、ベース仕様からの変更点を抜き出して、ベース仕様と変更後の仕様を比較して記載する。

例：

```diff
### コンテンツ追加手順

**before**

変更前のベース仕様の内容

**after**

変更後の仕様の内容

```
- 変更点は、変更前と変更後の両方を記載することで、どのような変更があったのかを明確にする。
