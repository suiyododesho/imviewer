3. よくある問題と解決策

❌ 問題: "サイトの読み込みに失敗しました"

原因: structure.json が読み込めない

対処法:

  1. file:// で開いている場合:
    • ローカルファイルシステムのセキュリティ制限が原因です
    • 解決: HTTPサーバーを使用してください（下記参照）
  2. HTTPサーバーを使用している場合:
    • ポート 8080 が使用可能か確認
    • 対象ディレクトリが site/ か確認
    • structure.json ファイルが site/ に存在してるか確認

⚠️ CORS エラーが表示される場合

HTTPサーバーの CORS 設定を確認してください。Python サーバーの場合、デフォルトで CORS は有効です。

4. HTTPサーバーの起動方法

方法 1: Python (最も一般的)

cd > site python -m http.server 8080

その後、ブラウザで以下をアクセス:

http://localhost:8080/index.html

方法 2: Node.js

npx http-server site/ -c-1 -p 8080

方法 3: VS Code Live Server 拡張

index.html を右クリック → "Open with Live Server"
