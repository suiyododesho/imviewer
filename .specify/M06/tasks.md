## M06 タスク分解

目的:
- メンテナンス実行速度を改善する
- SQLite をメンテナンス時の正本にし、運用サイトは静的ファイル配布を維持する
- UC1/UC2 を差分中心に再設計し、誤操作を減らす

前提:
- 非目標は「サーバ常駐 API 化」「ブラウザから SQLite 直接参照」
- 破壊的操作は plan/dry-run を先に実装し、apply は明示指定時のみ実行

## ユースケース

### UC1. コンテンツ追加

1. コンテンツの用意
2. 画像抽出、サムネイル画像作成、カバー画像登録
3. structure.jsonへのコンテンツ追加
4. structure.jsonからjsファイルの作成

### UC2. メタデータの編集

1. コンテンツの構造情報からメタデータ編集用のcsvを作成
2. csv編集（手動）
3. csvからstructure.jsonへ値を入力
4. structure.jsonからjsファイルの作成
